Automation In Action

From Code to Deployment.

This website uses GitHub Actions to automate the deployment process. Whenever the website is updated and changes are pushed to the repository, the workflow automatically publishes the latest version through GitHub Pages.

01 Update the website code
02 Push changes to GitHub
03 GitHub Actions runs the workflow
04 Website gets deployed
Want to update the team?
